# P0 通用 USB 生命周期用例

本用例不发送 DM 设备协议。源码基线、动态库来源和实际结果见同目录 `P0_USB_LIFECYCLE_TEST_REPORT.md`。

## A. 无模块可执行

| 范围 | 操作 | 预期 |
| --- | --- | --- |
| 提交失败 | 注入返回错误、抛异常、分配空指针、pin 失败 | 无效指针不进入原生 I/O；transfer/pin/句柄引用恰好释放一次 |
| 完成状态 | 注入成功、超时、stall、overflow、断开、取消、I/O 错误 | 状态映射正确；Task 完成前释放缓冲区固定及在途句柄引用 |
| token 取消 | 提前取消、提交期间取消、在途取消、完成与取消竞争 | 提前取消不分配；在途取消等待最终回调；完成先赢则返回成功 |
| 关闭排空 | 同句柄多传输、重复关闭、取消返回错误/抛异常 | 停止新异步提交；取消请求不是完成证明；等全部最终回调后才关闭 |
| 设备/context | 实际托管 Open/Close/Dispose，使用 fake native handle | 事件线程最后停止；允许重开；一个设备关闭不影响另一个 |
| 重开接口缓存 | 注入旧 claim/alt 状态，成功 Close 后重开 | 旧缓存清零；重开不跳过原生 claim |
| 设备引用/context 顺序 | 保留未打开设备/枚举引用，先 Dispose context | 业务调用拒绝；设备引用归还前原生 context 不退出；最终引用归还后关闭 |
| 超时恢复 | 不投递完成回调，调用 context Dispose | 5 秒后明确超时，资源未释放，context 未标已释放；补回调后可重试 |
| 自等待 | 从 fake 原生事件线程调用 Close/Dispose | 修改状态前拒绝，不 self-join |
| 热插拔 | 重复 arrival、未知 left、同步 ENUMERATE、注册失败 | 去重、忽略未知离线、失败回滚、引用平衡 |
| 通知 | 慢/异常订阅、队列过载、通知内注销/释放 | 不阻塞原生事件处理；错误隔离；满载上报；缓存/等待继续更新 |
| 后端 | native 能力有/无、轮询枚举失败 | 两后端筛选一致；250ms 轮询支持重连；枚举失败不误报全部离线 |
| 等待 | 同 finder 多等待、独立取消、超时后重试、稳定连接、重连 | 各自独立；无旧请求污染；总超时正确；结果引用由调用方拥有 |
| 原生故障 | 模拟 HandleEvents 返回错误 | 等待被唤醒/取消，不被慢用户通知拖住；明确需显式恢复 |
| 引用身份 | 指针 hash 冲突、重复变化 1000 轮 | 不把 hash 当设备身份；已保留引用最终全部归还 |

运行库/测试构建及 `dotnet test`；对回归套件重复运行。使用 `tools/UsbProbe` 做原生动态库集成冒烟：帮助、参数错误、无匹配枚举 1000 次、无匹配监控及 context 释放。探针默认不打开任何设备。

## B. 有模块后执行（本轮不得用 fake 结果替代）

Windows/Linux/macOS 分别执行：多设备枚举；boot/app、有/无 CDC；实际 vendor 接口 claim/release；异步 bulk 短包/超时/取消；读写中 Close；拔插/重连；设备被占用；单设备离线不影响另一设备；至少 1000 次打开/关闭与枚举；记录托管存活堆、原生内存、句柄及线程趋势。

使用已知可安全收发的测试设备和明确端点，不能对任意 USB 外设盲发测试数据。设备版本读取应放在独立 DM 探针中，不加入通用 USB 库。记录每个平台/架构/型号与固件构建，缺少条件的项目标“未测”。

拔插测试分项验收：在途请求终止及原生返回值、离线通知、旧句柄拒绝继续收发、旧句柄可关闭、新到达等待、新引用可打开并正常通信。不得仅因传输结果不是 NoDevice 就提前退出，漏掉重连诊断；也不得把 Pipe 一律改成 NoDevice。NoDevice 是否实际出现单独记录，重连通过不能替代错误码一致性结论。
